# VISUAL/RAW - Gambar Mentahan

Folder ini menampung gambar mentahan yang belum diproses. Gambar di sini TIDAK
boleh langsung digunakan dalam produksi.

Aturan pakai (lihat `NAZE-STANDARDS.md`, Persyaratan Wajib no. 8):

1. Hapus latar belakang gambar terlebih dahulu (cutout transparan, PNG).
2. Gambar wajib dianimasikan (keyframes, layers, atau camera); dilarang
   ditempel statis.
3. Hasil cutout yang siap dipakai dipindahkan ke folder visual final yang
   sesuai, bukan tetap di folder ini.
